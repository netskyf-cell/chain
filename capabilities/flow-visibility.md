# Capability: flow-visibility

> Product builder can visualize the flow of work between Claude interfaces, from design to shipped.

## Why this matters

A feature passes through several Claude surfaces. It may start as a mockup in Claude Design, become an intent and a spec in Claude.ai, and turn into a plan, code and a pull request in Claude Code. Each surface holds one piece, and the builder keeps the whole in their head. Making the flow visible removes the need to remember it.

## What done looks like (delivery-based, v1)

All features linked to this capability have shipped: their build pull request is merged to the default branch.
