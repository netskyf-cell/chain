# Capability: portfolio-vision

> Product leaders have a portfolio vision of all the features and outcomes from their AI-developed products.

## Why this matters

Leaders need a view that fits a review meeting: which capabilities are on track, which drifted, and where decisions are waiting, across several products. They should not need to open each repository to get it.

## What done looks like (delivery-based, v1)

All features linked to this capability have shipped. A leader can open one page, see every connected product, and share a read-only view.
